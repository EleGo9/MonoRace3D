Overview

MonoRace3D addresses the critical need for robust 3D object detection in high-speed racing environments, providing comprehensive annotations for vehicles, barriers, and track infrastructure from monocular camera views.

Racing-Focused

Specifically designed for autonomous racing scenarios with high-speed dynamics and challenging conditions

3D Annotations

Precise 6D pose annotations including position, orientation, and bounding boxes for all objects

Monocular Vision

Single camera setup enabling deployment in resource-constrained racing vehicles

Key Features

Precision Annotations

High-quality 6D pose annotations with sub-pixel accuracy for vehicles, barriers, cones, and track infrastructure

Diverse Conditions

Multiple weather conditions, lighting scenarios, and track surfaces to ensure robust model generalization

High-Speed Scenarios

Captures the unique challenges of high-velocity racing with motion blur and rapid scene changes

Easy Integration

Compatible with popular frameworks like YOLO, MonoDETR, and custom detection pipelines

Dataset Access

Download instructions and data format specifications 

# Clone the dataset repository

# Download the full dataset (requires authentication)
cd MonoRace3D-dataset
python download_data.py --split train --auth-key YOUR_KEY

# Load dataset in Python
from monorace3d import MonoRace3DDataset
dataset = MonoRace3DDataset(root='./data', split='train')
